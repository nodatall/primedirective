# Historical Starting-State Contract

This pre-packet stage contains an exact pinned subset of a historical repository. It is inspection-only. Keep every tracked source file byte-for-byte identical and preserve its executable mode. Do not stage changes or create commits, branches, tags, stashes, replacement refs, grafts, or shallow-history metadata before the evaluator supplies the fixed review packet. Any non-source inspection note must remain untracked.

The acceptance criteria, findings, remediation plan, and focused probes are deliberately withheld until the next stage. Use only the separately supplied Deliver contract and visible stage files. You may record non-source inspection or validation notes when useful.

Stop locally. Do not push, open a pull request, merge, install into the source environment, mutate the source checkout, or inspect evaluator-owned paths.
